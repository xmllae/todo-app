# ⏰ 订阅管理模块

## 概述

订阅管理模块已成功集成到您的导航网站中。这是一个功能完整的订阅服务管理工具，帮助您追踪和管理各种订阅服务的到期时间和费用。

## 🎯 核心功能

### 1. 导航栏入口
- 在导航栏中新增「⏰ 订阅」按钮
- 点击即可进入订阅管理界面
- 与现有的「日程」「看板」「设置」「统计」模块并列

### 2. 主界面展示

#### 统计面板
页面顶部显示三个关键指标：
- **订阅总数** - 当前管理的订阅服务总数
- **本月到期** - 本月即将到期的订阅数量
- **月均花费** - 根据订阅周期自动计算的平均月支出

#### 卡片式布局
- 响应式网格布局，自动适应屏幕大小
- 每张卡片显示一个订阅服务的完整信息
- 按剩余天数从近到远自动排序

### 3. 卡片信息

每张订阅卡片包含：
- 🎨 **服务图标** - 自定义 emoji 图标
- 📝 **服务名称** - 订阅服务的名称
- 📅 **到期日期** - 订阅到期的具体日期
- ⏳ **剩余天数** - 距离到期还有多少天（颜色编码）
- 💰 **费用金额** - 单次订阅费用
- 🔄 **订阅周期** - 月付/年付/一次性
- 📌 **备注信息** - 可选的备注说明

### 4. 颜色编码系统

剩余天数的颜色提示：
- 🔴 **红色** - 7天以内（紧急，需立即关注）
- 🟠 **橙色** - 8-30天（注意，即将到期）
- 🟢 **绿色** - 30天以上（充足，无需担心）

### 5. 即将到期提醒

当订阅剩余天数 ≤ 7 天时：
- 卡片右上角显示醒目的「⚠️ 即将到期」标签
- 卡片顶部显示红色条纹
- 帮助您及时续费或取消

### 6. 添加/编辑功能

#### 添加新订阅
1. 点击「＋ 添加订阅」按钮
2. 在弹出的表单中填写信息：
   - **服务名称** (必填) - 如：Netflix、Spotify
   - **图标** (可选) - 单个 emoji，默认为 📦
   - **到期日期** (必填) - 使用日期选择器
   - **费用** (必填) - 单次订阅金额
   - **订阅周期** (必填) - 选择月付/年付/一次性
   - **备注** (可选) - 添加任何备注信息
3. 点击「保存」按钮

#### 编辑订阅
1. 在卡片上点击「✏️ 编辑」按钮
2. 修改需要更新的信息
3. 点击「保存」按钮

#### 删除订阅
1. 在卡片上点击「🗑️ 删除」按钮
2. 确认删除操作
3. 订阅将被永久删除

### 7. 数据存储

所有订阅数据自动保存到浏览器的 localStorage 中：
- ✅ **自动保存** - 无需手动操作
- ✅ **本地存储** - 数据仅保存在您的浏览器中
- ✅ **持久化** - 关闭浏览器后数据仍然保留
- ✅ **隐私保护** - 不上传到任何服务器

## 📱 响应式设计

订阅模块完全响应式，在各种设备上都能完美显示：
- 💻 **桌面浏览器** - 多列网格布局
- 📱 **平板设备** - 自适应列数
- 📲 **手机设备** - 单列或双列布局

## 🚀 快速开始

1. **打开应用** - 访问您的导航网站
2. **进入订阅模块** - 点击导航栏中的「⏰ 订阅」
3. **添加订阅** - 点击「＋ 添加订阅」按钮
4. **填写信息** - 输入订阅服务的详细信息
5. **保存** - 点击「保存」按钮
6. **管理** - 根据颜色提示及时续费或管理订阅

## 💡 使用场景

- 📺 **流媒体订阅** - Netflix、Disney+、Spotify、Apple Music 等
- ☁️ **云服务订阅** - AWS、阿里云、腾讯云、Azure 等
- 🛠 **工具订阅** - GitHub Pro、Figma、Adobe Creative Cloud 等
- 📱 **应用订阅** - 各类 App 内订阅服务
- 🏋️ **会员服务** - 健身房、会员卡、俱乐部等定期费用

### 关键函数

| 函数名 | 功能 |
|--------|------|
| `rSubscriptions()` | 渲染订阅列表 |
| `openSubModal(id)` | 打开添加/编辑表单 |
| `saveSub(id)` | 保存订阅信息 |
| `editSub(id)` | 编辑订阅 |
| `delSub(id)` | 删除订阅 |
| `calcDaysLeft(date)` | 计算剩余天数 |
| `getSubColor(days)` | 获取颜色编码 |

### 数据结构

订阅对象结构：
```javascript
{
  id: 1234567890,           // 唯一标识

  cost: 99.99,             // 费用
  cycle: "month",          // 周期（month/year/once）

}
```
