- ✅ 风格与现有导航栏保持一致

- ✅ 到期前7天在卡片上显示醒目提示

## 🚀 使用方式

### 快速开始
1. 打开应用
2. 点击导航栏「⏰ 订阅」
3. 点击「＋ 添加订阅」
4. 填写订阅信息
5. 点击「保存」

### 管理订阅
- **编辑** - 点击卡片上的「✏️ 编辑」按钮
- **删除** - 点击卡片上的「🗑️ 删除」按钮
- **查看** - 卡片上显示所有关键信息

## 💻 技术实现

### 技术栈
- HTML5
- CSS3（使用现有项目的 CSS 变量）
- JavaScript（原生，无依赖）
- localStorage API

### 关键函数
- `rSubscriptions()` - 渲染订阅列表
- `openSubModal(id)` - 打开表单
- `saveSub(id)` - 保存订阅
- `editSub(id)` - 编辑订阅
- `delSub(id)` - 删除订阅
- `calcDaysLeft(date)` - 计算剩余天数
- `getSubColor(days)` - 获取颜色编码

### 数据结构
```javascript
{
  id: 1704067200000,        // 唯一标识
  name: "Netflix",          // 服务名称
  icon: "📺",              // 图标
  expireDate: "2024-12-31", // 到期日期
  cost: 99.99,             // 费用
  cycle: "month",          // 周期
  note: "家庭套餐"         // 备注
}
```
